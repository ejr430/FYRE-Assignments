#Programming Activities


Program 1: "Hello World" (Prints Hello World)


Program 2: "My name is" (Prints My name is ___)


Program 3: "My name is" with a variable (Prints My name is ____ with a variable)


Program 4: Blinking LED (LED flickers)


Program 5: Buttons & Lights (One light is activated by a switch, the other light is activated by another switch and if the other light is on)


Program 6: Servo Motor (Rotates the Servo Motor 180 degrees)


Program 7: ADC Readings (measures how much voltage goes through our rain drop sensor)
